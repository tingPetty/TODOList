# Desktop Todo Lite 视觉改造方案：小芽手帐

> 日期：2026-09-19 · 状态：核心界面已实施，详见 [实施记录](GREEN_CARTOON_IMPLEMENTATION.md)
>
> 本文保留原设计提案，基于用户提供的四张截图和 PySide6 界面结构制定。后续用户已授权实施；实际完成范围、验证结果和取舍以实施记录为准。

## 1. 设计方向

把软件设计成一份放在桌面上的「小芽手帐」：奶油色纸面、抹茶绿标签、圆润的深绿描边，加上一只安静陪伴的小芽。任务列表像手帐里的待办页，专注页像书桌上的小盆栽，统计和历史像翻开的记录本。

**关键词：清爽、圆润、轻卡通、绿色、紧凑、安静陪伴。**

卡通感来自轮廓、比例和细节：圆角复选框、略带厚度的按钮、小叶片页签、简洁的小芽表情。正文使用清晰的系统字体；不靠满屏插画、花体字或持续晃动制造风格。

建议保留产品名称 `Day Todo`，将「小芽手帐」作为视觉主题名。顶部只放名称和小芽图标，不增加口号占用空间。

### 第一眼应当发生的变化

| 当前界面 | 新方案 |
|---|---|
| 灰蓝半透明，桌面文字透过窗口干扰阅读 | 奶油白不透明内容底，浅绿色外框 |
| 外壳和内容卡片使用相近的深色，大块套大块 | 一层窗口外壳、一层纸面；任务行以留白分隔 |
| 日期、任务输入、重要选项挤在同一行 | 输入独占第一行，日期和重要选项放第二行 |
| 黄色下划线页签和蓝灰卡片不成体系 | 浅绿分段页签，深绿色选中胶囊 |
| 每行都有红灰色删除方块 | 常驻低强调垃圾桶，悬停或键盘聚焦时才加强颜色 |
| 专注页大面积空白，数字悬在上方 | 小芽、数字、状态、按钮构成紧凑的中央组合 |
| 统计、历史、编辑窗口各用一套颜色 | 所有弹窗使用相同纸面、字体、按钮和图标 |

## 2. 范围与功能约束

覆盖主窗口、Todo 页、专注页、任务统计、专注历史、编辑任务、更多菜单、日期选择器、提示和空状态。

保留回车添加、日期分组、重要标记、仅复选框切换完成、双击编辑、删除、拖拽排序、跨组改日期、折叠已完成、统计查询、专注暂停/继续/结束、窗口置顶、开机自启、拖动和缩放。

保留两个页面及 `Ctrl+1` / `Ctrl+2` 切换方式；页面切换不重置输入、列表位置或计时状态。维持当前关闭按钮的「退出软件」含义，不把它改成最小化或隐藏。

本轮不引入积分、签到、植物养成存档、倒计时番茄钟、账号或云同步。小芽只表达界面状态，不增加用户需要维护的新系统。

## 3. 视觉规范

### 3.1 配色

绿色用于交互和重点，奶油白承担大部分阅读背景。黄色只点缀重要事项，红色只用于删除和错误。

| Token | 颜色 | 用途 |
|---|---|---|
| `canvas` | `#F6F8ED` | 窗口与弹窗基础底色 |
| `paper` | `#FFFEF7` | 任务纸面、输入框、图表背景 |
| `surface_soft` | `#E8F0D9` | 页签轨道、轻量分组底色 |
| `primary` | `#3F6B45` | 主按钮、选中页签、已选复选框 |
| `primary_hover` | `#345A3A` | 主按钮悬停 |
| `primary_pressed` | `#294A30` | 主按钮按下 |
| `accent` | `#BBD78C` | 小芽叶片、图表淡填充、装饰 |
| `ink` | `#263C2D` | 正文、标题、计时数字 |
| `ink_secondary` | `#59664E` | 日期、说明、已完成任务文字 |
| `outline` | `#607A50` | 交互控件边界、关键轮廓 |
| `divider` | `#D6DFC8` | 非交互分隔线、图表网格 |
| `important_bg` | `#F7E7AD` | 重要标记浅黄底 |
| `important_ink` | `#71561F` | 星形重要标记与文字 |
| `danger_bg` | `#F8E4DD` | 删除悬停、错误提示浅底 |
| `danger_ink` | `#9B453A` | 删除图标、错误文字 |

主按钮文字用 `paper`，普通内容用 `ink`。`accent` 不承载白色小字；辅助文字不通过降低整个控件透明度处理。实现验收时核对实际颜色组合：正文目标对比度至少 4.5:1，关键控件边界和焦点标识至少 3:1；以上为设计目标，需在最终渲染后验证。

### 3.2 形状与质感

- 窗口外壳圆角 20 px，内容纸面 14 px，输入框和按钮 10 px，任务行悬停底 8 px。
- 外框使用 2 px 深绿描边，内部控件使用 1–1.5 px 描边；避免所有容器都加粗边框。
- 主按钮可以有 2 px 向下偏移的深绿底边，按下时收回，像轻轻按下一枚软胶印章。
- 阴影只用于窗口或浮层，强度轻；列表项不逐行加投影。
- 内部背景完全不透明。主窗口可继续保留透明圆角区域，但不让桌面穿透内容区。
- 装饰只放标题旁、空状态或专注主体，不在文字后铺纹理。

### 3.3 字体、尺寸与间距

尺寸均指 Qt 逻辑像素，按系统 DPI 缩放；不通过强制固定整个窗口大小解决布局问题。

| 项目 | 建议值 |
|---|---|
| 正文字体 | Microsoft YaHei UI；缺失时回退系统无衬线字体 |
| 窗口标题 / 页面标题 | 17–18 px / 16 px，粗体 |
| 任务正文 / 输入内容 | 14 px |
| 日期、辅助说明 | 12 px |
| 计时数字 | 默认 42 px，紧凑模式 36 px；使用等宽数字字体，如 Consolas |
| 外壳内边距 / 纸面内边距 | 12 px / 12 px |
| 间距基准 | 4、8、12、16、24 px |
| 普通输入和按钮高度 | 36 px |
| 图标按钮点击区域 | 至少 32 × 32 px；图标本体 16–18 px |
| 复选框 | 图形 20 × 20 px，点击区域至少 28 × 28 px |
| 任务行 / 历史记录行 | 最小 40 px / 64 px |

保留当前默认窗口 `430 × 420` 和最小窗口 `360 × 360`，先通过实际排版验证。默认高度下以一组日期标题、约 3–4 条任务同时可见为目标；更多任务在列表内滚动。重要信息和可用点击区域优先于装饰。

## 4. 主窗口与导航

顶部保持「小芽图标 + Day Todo」「更多」「关闭」三部分。图标及文字共用拖动区域，按钮区域不触发窗口拖动。

下方使用一条浅绿分段导航：`✓ Todo` 与 `◷ 专注`，两项等宽。选中项为深绿胶囊配奶油白字，未选中项为深绿文字。取消黄色下划线，选中、悬停、键盘焦点分别有明确状态。

右下角缩放柄改为两条低强调短斜线，鼠标移入显示标准缩放光标；外形可以像叶脉，但不能失去可发现性。更多菜单中置顶、开机自启保持勾选状态；使用与正文一致的浅色菜单和深色文字。

弹窗第一阶段保留系统标题栏，正文统一主题，不重复添加关闭按钮。系统标题栏受 Windows 设置控制，不承诺与自绘主窗口完全一致；不要为了颜色统一立即引入一套无边框弹窗拖动和缩放机制。

## 5. Todo 页：清爽的任务手帐

### 5.1 布局示意

以下为结构线框，符号仅说明位置，正式实现用统一 SVG 图标。

```text
╭────────────────────────────────────────╮
│ 小芽  Day Todo                  ⋯   ×  │
│ ┌────── ✓ Todo ──────┬──── ◷ 专注 ────┐ │
│ └───────────────────┴───────────────┘ │
│  任务清单                      [统计]  │
│  ┌───────────────────────────┐ [＋]   │
│  │ 写下一件要做的小事…       │        │
│  └───────────────────────────┘        │
│  [日期 2026-09-19 ▾]  [☆ 重要]        │
│                                        │
│  今天 · 09/19            收起已完成 1  │
│  □  跑实验                         ♧  │
│  □  投两家公司                 ☆   ♧  │
│  □  整理百度面经                   ♧  │
│  ☑  改一下简历排版                 ♧  │
│                                     ╱  │
╰────────────────────────────────────────╯
```

示意中的 `♧` 位置表示垃圾桶按钮，不使用叶片替代删除图标。完成项实际有删除线。

### 5.2 添加任务

- 第一行是可伸缩的任务输入框和 36 px 添加按钮；回车与点击加号行为一致。
- 第二行放日期选择器和「☆ 重要」可切换按钮。日期完整显示 `yyyy-MM-dd`，建议宽 140 px，最终按字体测量校正。
- 重要选中态使用浅黄底、实心星和「重要」文字；不能只靠颜色变化。
- 输入焦点使用深绿色外圈；空内容提交时显示「先写下一件小事吧」，保留焦点，不弹阻断式对话框。
- 新增成功后任务按原规则进入相应日期组。输入框清空、重要标记重置、日期保留等行为沿用当前实现。

### 5.3 任务行与分组

- 默认任务行无边框，悬停呈浅绿底；选中态与悬停态有所区别，键盘焦点额外显示轮廓。
- 复选框为圆角方形，选中后深绿底、奶油白对勾。仅点击复选框切换完成，点击文字不意外完成任务。
- 重要任务保留文字加粗，右侧显示小星标，替换当前彩色感叹号字符。
- 已完成文字使用 `ink_secondary` 和删除线，复选框仍清晰；不要淡到难以辨认。
- 删除按钮常驻但不铺红色方块；悬停和键盘聚焦显示浅红底，并提供「删除任务」提示及可访问名称。
- 双击文本保留编辑；长任务单行省略，悬停展示完整任务及编辑提示，编辑窗可查看和修改全文。
- 日期标题是轻量文字行，折叠按钮使用「展开已完成 2 / 收起已完成 2」。保留现有日期顺序与组内排序。
- 拖拽时使用 2 px 绿色插入线；跨日期组时浅绿突出目标组标题，并显示「移到 09/20」，避免只用颜色提示落点。

### 5.4 空状态

无可见任务时显示一张 48–64 px 的小芽插画，文案：「这里还没有待办」「从一件小事开始吧」。输入区始终可用。

有已完成记录时仍显示原日期组和折叠入口，不用庆祝插画替换整个列表。可在刚完成任务时短暂显示「又完成一件小事」，不强行宣称所有任务都已完成。

## 6. 专注页：小芽陪你坐一会儿

### 6.1 主体布局

```text
╭────────────────────────────────────────╮
│ 小芽  Day Todo                  ⋯   ×  │
│       Todo          [ ◷ 专注 ]         │
│  专注空间                      [历史]  │
│                                        │
│              一株安静的小芽            │
│                 00:18:42               │
│              整理旅游购票时间          │
│                 正在专注               │
│                                        │
│          [Ⅱ 暂停]  [结束并保存]        │
│                                        │
╰────────────────────────────────────────╯
```

计时器是第一视觉重点，小芽是第二重点。装饰约 56–72 px，不用巨型盆栽挤压操作区。整体居中，窗口变高时增加主体上下留白；窗口变小时先缩小或隐藏装饰。

### 6.2 状态设计

| 状态 | 小芽表现 | 内容与操作 |
|---|---|---|
| 未开始 | 两片叶子、睁眼静坐 | 名称输入、`00:00:00`、绿色「开始专注」按钮 |
| 进行中 | 叶片舒展，保持静止 | 名称、真实累计时间、文字「正在专注」、暂停、结束并保存 |
| 已暂停 | 小芽闭眼，旁边小暂停符号 | 时间冻结、文字「已暂停」、绿色「继续」、结束并保存 |
| 刚结束 | 小芽微笑一次 | 短暂提示「已保存这段专注」，随后回到未开始态 |

「结束并保存」使用描边次按钮，不使用危险红色；它是正常完成流程。暂停和继续用图标配文字，避免只凭 `Ⅱ`、`■` 猜含义。

保留正向计时，不画暗示倒计时的进度环，不显示未经定义的百分比。小芽表情仅映射会话状态，不根据计时时长伪造学习效果或奖励等级。小时超过两位时数字区域允许适当缩字，不截断。

空名称开始时在输入框下显示校验文案，直到用户输入或成功开始；普通计时刷新不应立即覆盖错误提示。长会话名称可显示两行，超出内容通过提示查看，按钮位置保持稳定。

## 7. 任务统计：一页清楚的记录

建议默认尺寸维持约 `550 × 510`，纸面为奶油白。页面按「标题说明 → 趋势图 → 日期查询 → 明细列表」排列，图表不再套一层厚重深色边框。

- 标题「任务统计」，说明「近 30 天 · 按任务日期统计已完成项」。
- 趋势线用 `primary`，线宽 2 px；浅绿面积填充，节点为小圆点。悬停节点可提示完整日期和数量。
- 横轴约每 5 天一个标签，纵轴使用非负整数；零数据时纵轴至少显示 0 和 1。
- 淡化网格，只保留必要参考线；坐标文字使用深色，背景与纸面一致。
- 图表查询日期用细竖线或选中点标识，并保留日期选择器作为可靠操作入口。
- 自动缩放改为明确的「重置视图」轻量入口；若接入此入口则隐藏重复的内置 `A` 控件。
- 明细标题使用「09 月 19 日的任务 · 已完成 0 项」，而不是暗示实际在当天完成。
- 无记录时显示小芽捧着空白纸，文案「这个任务日期下还没有已完成项」。

**数据口径必须保持准确：** 当前 `StatisticsService` 按 `task.task_date` 聚合已完成任务，不按真实完成时间聚合。这次样式改造不新增完成时间字段，不把曲线描述成真实的每日完成行为。若以后要改统计口径，应单独设计数据迁移。

## 8. 专注历史：清晰的小票列表

默认约 `390 × 430`，使用与统计窗口相同的基础底色和卡片。

- 顶部显示「专注历史」及「最近 7 个自然日」说明，日期以现有北京时间规则解释。
- 每条记录左侧为名称和完整日期时间，右侧为等宽时长及低强调垃圾桶。
- 名称最多两行，日期单独一行；时长如 `01:54:17` 右对齐，长时长不得截断。
- 行与行之间使用细分隔线或 8 px 留白，不为每条记录加粗边框。
- 名称溢出时提供完整提示，不让右侧时长和删除按钮被推走。
- 空状态：「最近 7 天还没有专注记录」「结束一段专注后，会记录在这里」。
- 保留现有记录排序与删除行为；本轮不新增排行榜、连续天数或复杂筛选。

## 9. 编辑、菜单与其他小界面

编辑任务弹窗采用纵向表单：任务内容、日期、重要标记。底部「取消」为描边按钮，「保存」为绿色实心按钮，替换通用英文按钮文案。错误提示在字段附近显示，保留已输入内容。

日期弹出日历统一奶油底、深色日期文字；选中日深绿底白字，今天使用描边，禁用日降低强调但保持可辨认。明确区分「今天」和「选中日期」。

更多菜单统一内边距、圆角和选中底色；工具提示使用浅底深字。滚动条采用细绿滑块、浅色轨道，悬停增强调；不要为了极简移除滚动提示。删除及系统错误提示沿用明确操作名称，避免使用「拔掉小苗」之类隐喻替代功能。

## 10. 小巧思与克制规则

| 小巧思 | 触发与表现 | 约束 |
|---|---|---|
| 小芽签名 | 标题图标是两片叶子和小圆脸 | 24 px 内仍可辨识，不承担必要操作 |
| 盖章式勾选 | 勾选时对勾轻弹一次，约 160 ms | 状态立即更新，动画不能延迟保存和排序 |
| 叶片页签 | 选中标签旁一片小叶子或简洁线性图标 | 不与文字抢位置，紧凑模式可省略 |
| 专注表情 | 开始、暂停、结束时切换静态表情 | 不每秒跳动，不用持续动画分散注意力 |
| 纸角收纳 | 空列表右下角一处小纸角或叶片 | 有任务时移除，不挡滚动条和缩放柄 |
| 温柔反馈 | 添加、结束后出现简短状态提示 | 不抢焦点、不播放声音、不堆叠通知 |

核心版本只实现静态小芽和状态切换即可形成风格。动画是最后一层润色：单次 120–180 ms，无循环粒子和全屏庆祝；减少动态模式下直接切到终态。反馈不使用随机文案，避免同一操作含义不稳定。

## 11. 紧凑布局与可用性

- 宽度低于 400 px 时，横向内边距可从 12 降至 8 px，图标旁的可选文字可省略，但日期、任务输入和主要动作完整保留。
- 添加区始终采用两行结构，不再因窄屏退回拥挤单行。
- `360 × 360` 下优先保证输入区、页签与列表可用；任务列表内部滚动，专注小芽缩至 40 px 或隐藏。
- 正文不小于 13 px；先收缩留白与装饰，再调整字号。
- 在 100%、125%、150%、200% Windows 缩放下检查文字和按钮，不用单一截图推断适配成功。
- 图标按钮有悬浮提示和可访问名称；键盘 Tab 焦点清晰，空格可切换复选框，弹窗保留标准键盘行为。
- 重要、暂停、错误、完成状态同时通过文字或形状表达，不只靠绿色深浅区分。
- 当按钮因状态不可用时，提供可辨认的禁用态；不要通过隐藏所有操作让界面难以理解。

## 12. 对现有代码的落地映射

当前已有共享主题和组件，适合直接在表现层改造。单改全局 QSS 不够：部分行文字、历史窗口、图表颜色仍在各自文件中硬编码，需要同时收敛。

| 文件 / 区域 | 改造内容 |
|---|---|
| `todolite/presentation/styles/theme.py` | 建立颜色 token；替换灰蓝透明主题；统一弹窗、菜单、日历、输入框、焦点和按钮状态 |
| `todolite/presentation/styles/metrics.py` | 收敛圆角、行高、间距、点击区域和紧凑尺寸 |
| `todolite/presentation/styles/icons.py` | 增加统一 SVG 图标加载和状态颜色规则，减少 Unicode 符号按钮 |
| `todolite/presentation/windows/main_window.py` | 浅色不透明外壳、顶部留白、拖动区域、缩放柄布局 |
| `widgets/surface_card.py`、`tab_bar.py`、`icon_button.py` | 区分外壳/纸面/轻量容器，胶囊导航和统一按钮状态 |
| `pages/todo_page.py` | 两行添加区、加号入口、校验提示、紧凑适配 |
| `widgets/task_row.py`、`task_group_header.py`、`task_list.py` | 移除硬编码文字颜色，统一完成/重要/悬停/拖拽样式 |

### 素材与技术选型

- 主界面图标建议统一 24 × 24 viewBox、圆端点描边；小尺寸下轮廓简化，保持一致笔画。
- 小芽使用 3–4 张轻量 SVG：默认、专注、暂停、微笑。优先程序原生矢量资源，不引入在线图片依赖。
- 保持 PySide6 与现有 pyqtgraph；不为主题改造引入 WebView 或另一个 UI 框架。
- QSS 处理配色、边框和状态；真正的阴影或轻微动效使用 Qt 绘制/动画机制，不能直接套用浏览器的 `box-shadow`、`transform` 或 `transition`。
- 动态属性改变后按需更新控件样式；不要在 500 ms 计时刷新里重复加载 SVG、重建布局或播放动画。
- 计时继续读取现有服务；动画不参与时间累计、任务存储或数据清理。
- 任务列表目前刷新时重建条目，完成反馈应在不延迟服务操作的前提下实现；必要时只在稳定的页级提示区域播放，避免动画对象随列表刷新被销毁。

以下保留提案中的完整实施计划；实际完成情况见实施记录，未逐项落实的细节不在此标记为完成。

- [ ] 主窗口、统计、历史、编辑、菜单和日历均使用同一套绿色与纸面色。

## 15. 设计取舍

优先投入在不透明纸面、两行输入、统一弹窗和清晰状态上，这四项直接解决截图中的主要问题。小芽、叶片和盖章反馈让软件有个性，但必须服从内容密度与操作效率。

最终效果应当是一件安静、可爱、容易阅读的绿色桌面工具：任务始终是主角，小芽只负责陪伴。
